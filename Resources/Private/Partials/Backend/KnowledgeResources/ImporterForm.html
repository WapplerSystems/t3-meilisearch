One card per registered KnowledgeResourceSourceImporter — the import slug, label and field list all come from PHP via describeFields(). Adding a new importer creates a new card here without any template change. Arguments: - importer {name, label, description, fields[]} - knownLanguages int[langId] => label - defaultTargetFolder placeholder for folder pickers - folderBrowserUrl CSRF-tokened element-browser URL - token BE form CSRF token - runImporterUrl controller endpoint Detect any file field so we set enctype only when needed — avoids multipart parsing overhead for the all-text importers.
