Transcript first, input below it: the answer grows downwards and the reader follows it, so the field they type the next question into has to be where their eyes already are. Inside the chat widget the field additionally sticks to the bottom of the scrolling panel (Rag.css).
Component styles for the streamed answer (faded while building, spinner on top). Separate from RagEmbed.css, which only dresses the bare embed document. Static contact card — only in fallback.show=always, where it is permanently visible and needs no answer to anchor it. In the default onlyEmpty mode the streamed answer decides per turn and the card arrives as a `fallback` frame (RagStream.js), because this shell is rendered before any answer exists and could never make that call itself.
