Meilisearch — Help docs

DITA-OT XHTML help topics live in tx_wsmeilisearch_helpdoc and are pushed to Meilisearch as a separate doc type (type=help). Re-imports purge and rebuild the language scope so the table tracks whatever the docs team last regenerated. Individual records can be tweaked in the List module — boost, hidden flag, or abstract overrides survive the next import only if you leave the identifier alone.

Purge by language

Hard-deletes every helpdoc row in the chosen language together with its FAL references. Meilisearch keeps the now-orphaned help-<uid> doc IDs until the next reindex.

Upload single document PDF / DOCX / HTML / Markdown / Office

Drop a single curated document into the knowledge base — useful for one-off uploads (FAQ PDF, internal handbook, customer brief) that don't fit the DITA-OT import workflow. Tika extracts the body text from the uploaded file (PDF / DOCX / Office / HTML / EPUB / TXT etc., per meilisearch.tika.allowedMimeTypes); the editor-supplied title + abstract drive how the entry appears in search results.

FAL combined identifier (storage:path). The uploads/ subfolder is added automatically.

After upload the new entry is visible in the List module immediately. Run ws_meilisearch:reindex (or the Overview tab) to push it to Meilisearch.

Batch-import from FAL folder PDF / DOCX / HTML / Markdown / …

Walk a fileadmin folder and create one helpdoc per file in it. Existing sys_file rows are reused — files are not copied. Good for dropping a stack of PDFs into fileadmin/handbooks/ via FileList and then turning them into searchable entries in one shot.

FAL combined identifier (storage:path). Use the picker to pick visually.

Run ws_meilisearch:reindex (or the Overview tab) afterwards. The folder importer is also available via ws_meilisearch:import-help-docs --importer=folder -f folder=1:/handbooks/.

Upload ZIP bundle many docs at once

Upload one .zip containing many documents — each entry becomes its own helpdoc. Path-traversal entries and dotfiles are dropped automatically. Cap of 1000 entries per archive (zip-bomb guard).

A zips/ subfolder is added automatically.

Run ws_meilisearch:reindex (or the Overview tab) afterwards.

Import from URL list HTTP fetch

Fetch every URL, store the response in fileadmin, run Tika for the body. Use for public wiki pages, S3-hosted PDF links, customer docs hosted elsewhere. Only http and https are accepted. Blank lines and lines starting with # are skipped.

A urls/ subfolder is added automatically.

Run ws_meilisearch:reindex (or the Overview tab) afterwards. Failed URLs are listed in the flash message; full detail in the log.
