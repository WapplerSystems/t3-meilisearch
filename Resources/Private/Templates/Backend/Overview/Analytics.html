Meilisearch — Analytics

Aggregierte FE-Suchanfragen aus tx_wsmeilisearch_search_log. Nur opt-in pro Site via meilisearch.analytics.enabled = true. Es werden ausschließlich {Query, Trefferzahl, Site, Sprache, Quelle, Zeitstempel} gespeichert — keine IPs, keine User-IDs.

Analytics ist aktuell auf keiner Site aktiviert. Setze meilisearch.analytics.enabled: true im Site-Setting, damit zukünftige Such-Aufrufe protokolliert werden.
