Meilisearch — RAG regression tests

Quality-assurance harness for the RAG pipeline. Each row in tx_wsmeilisearch_ragtest is a (question, expected answer, threshold) triple; "Run" asks the RAG provider the question and scores the actual answer against the expected one via embedding cosine similarity. A score below the threshold means the model / prompt / corpus has drifted away from the expected answer — a real quality regression. The scheduler task runs the same engine on cron; this tab is for ad-hoc triage.
